# measurement-file-namer（計測ファイル一括命名ツール）

1回の試験で取れた計測ファイル（NR-X100 の `.xlsm`/`.csv`、DS-5100 の `.csv`、DynoWare の `.dwd` など）を一度に並べて、
**共通の試験条件から名前を付け、指定フォルダへまとめて保存する** Windows 向けの小さなツールです。

「`データ(3).csv` が何回目のどれだったか」を思い出す作業から研究者を解放するために生まれました。

## 起動のしかた

フォルダの中の **`start_app.bat` をダブルクリック** するだけです。
**追加のインストール（pip）は不要** です。Python 標準の tkinter と、Windows に最初から入っている PowerShell だけで動くので、
社内プロキシで pip が通らない PC でも使えます。

- 開いている Excel の操作は、pywin32 が入っていればそれを、なければ PowerShell を使います。
- tkinterdnd2 が入っていればドラッグ＆ドロップも使えます（なくてもボタンから追加できます）。
- `build_exe.bat` は exe を作るためのもので、PyInstaller を pip で入れるため、pip が通るネットワークが必要です。
- バッチファイルは Windows の日本語環境で文字化けしないよう Shift_JIS（CP932）で保存しています（GitHub 上では文字化けして見えます）。

## 使い方（計測した直後、Excel が開いたままのとき）

計測ソフトが「データの入った未保存の Excel」を開いた状態で、次の順に操作します。

1. `start_app.bat` をダブルクリックして起動（exe を作った場合は `SokuteiNamer.exe`）
2. 一番上の「**自由な名前**」に好きな名前を入れる（例: `アルミ_5000rpm_びびり有`）
3. **「開いているExcelを取り込む」** を押す → 未保存のブックにチェックが入った一覧が出るので「取り込む」
4. 表の「新しい名前」を確認（機器名が違えばダブルクリックで直せます）
5. 保存先フォルダを選んで **「一括保存 ▶」**

`アルミ_5000rpm_びびり有_NRX.xlsx` として保存され、「CSV も書き出す」にチェックがあれば
1枚目のシートが `アルミ_5000rpm_びびり有_NRX.csv` としても保存されます。機器名が要らなければ
「後ろに機器名を付ける」のチェックを外します。1件ずつ別の名前にしたいときは、表の「新しい名前」をダブルクリックして書き換えます。
同じ名前がすでにあれば `_2` が付くので、上書きされることはありません。保存先と命名ルールは次回起動時も覚えています。

## 使い方（もう保存済みのファイルを整理するとき）

ファイルを表にドラッグ＆ドロップ（または「ファイル追加」「フォルダ追加」）してから「一括保存 ▶」。
元ファイルは消さずにコピーします。

例：試験No 2・500 Hz・0.65 V・1回目

| 元 | 新しい名前 |
|---|---|
| 開いている `Book1`（NR-X100 が開いた Excel） | `2-500-0.65-1_NRX.xlsx`（＋ `.csv`） |
| `DS5100_export.csv` | `2-500-0.65-1_DS5100.csv` |
| `20260423_test2.dwd` | `2-500-0.65-1_DYNO.dwd` |

## 試験条件から名前を作る（任意）

「試験条件から作る」を選ぶと、試験No・周波数・電圧・回数から名前を作ります（保存のたびに回数は +1）。
形は「命名ルール」欄で変えられます。既定は `{test}-{freq}-{volt}-{run}_{inst}` です。

| トークン | 意味 |
|---|---|
| `{name}` | 自由な名前 |
| `{date}` | 日付（YYYYMMDD、既定は今日） |
| `{test}` | 試験No |
| `{freq}` | 周波数 [Hz] |
| `{volt}` | 電圧 [V] |
| `{run}` | 回数（保存が成功すると自動で +1） |
| `{inst}` | 機器タグ（NRX / DS5100 / DYNO / LK / RP など） |
| `{memo}` | ファイルごとのメモ |
| `{orig}` | 元のファイル名 |

空のトークンは自動で詰めます（機器タグが空なら `_` も消えます）。ファイル名に使えない文字は `_` に置き換えます。

## 安全のための仕様

- 開いている Excel は、Excel 自身の「名前を付けて保存」で保存します（保存形式は .xlsx / .xlsm / .csv から選択）。
- ファイルは既定で **コピー**。元ファイルは消しません（「移動」にチェックしたときだけ消えます）。
- 同じ名前のファイルがあっても **上書きしません**（`_2`, `_3` … を付けます）。
- コピー後にサイズを照合し、保存先の `rename_log.csv` に「元ファイル → 新しい名前」を追記します。
- 機器タグは拡張子と CSV の先頭数行（KEYENCE / O-Solution / DynoWare）から推定します。表の「機器」をダブルクリックすると直せます。
- 「新しい名前」をダブルクリックすると、その1件だけ手で名前を付けられます。

## exe にする

`build_exe.bat` を実行すると `dist\SokuteiNamer.exe` ができます（PyInstaller・tkinterdnd2・pywin32 を pip で入れます）。
tkinterdnd2 がない環境でも動きますが、その場合ドラッグ＆ドロップは使えず、ボタンからの追加になります。
